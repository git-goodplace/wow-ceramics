# Wow Ceramics — лендинг

Одностраничный сайт гончарной студии Wow Ceramics (Казань, ул. Маяковского, 20).
Статический HTML + CSS + немного JS, без сборки и зависимостей.

Публикация: GitHub Pages, ветка `main`, корень репозитория.

Что заменить перед финалом:
- фотографии в `assets/photos` (сейчас — кадры студии из открытых источников);
- изображения работ в `assets/works` (сгенерированные заглушки);
- цены: в блоках форматов сейчас «по запросу»;
- приём заявок: в `index.html` есть константа `FORM_ENDPOINT` — если её заполнить
  адресом Formspree/Getform, форма будет отправлять заявки на почту. Пока не заполнена,
  кнопка «Отправить заявку» открывает WhatsApp студии с готовым текстом заявки.
